# Phase 7: 准备已有经验与任务能力查找上下文

> 保留现有配置键 `expert_experience`。仅在执行计划含该步骤时读取；单仓与多仓一致。

## 执行步骤

1. 在 Phase 6 后、Phase 8 前，提取需求目标、代码仓、约束及已有设计上下文。若有 `--query`，将其作为后续任务能力查找的关键词参考。
2. 可复用当前项目中已获取且适用的经验，辅助设计决策；不要在任务形成前无条件调用独立经验脚本或检索经验。
3. 无可复用经验时直接继续生成任务，不要求创建临时经验文件。
4. Phase 8 / M-2 任务形成后，再按 本 Skill 的「Skill 与经验消费规则」中的 SDD 路径统一查找与获取：业务场景匹配未命中时，分别检索最多 3 个 Skill 和 3 条经验；通用能力直接检索 Skill。
5. 将实际选用内容下载到项目级目录，关联到对应 tasks.md，并按需完善设计决策。不要把任务关联写到 expert_experience.md 或其他索引。
6. 保留任务仍引用的本地经验与 Skill，供 core-apply 消费。

## 关闭语义

关闭 `expert_experience` 仅跳过本阶段已有设计经验的准备，不影响 Phase 8 / M-2 任务形成后的能力查找、项目级获取及 tasks.md 同步；查找失败不阻断原任务。
