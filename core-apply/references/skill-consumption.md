# Step 9: 任务 Skill 准备与消费（内置可启停步骤，默认关闭）

## 启用门控

本文件由内置步骤 `skill_consumption` 加载。仅当根执行计划 `docs/.flow_context/execution-plan-core-apply.json` 的 `steps` 含 `config_key=skill_consumption`、`type=built_in`、`enabled=true` 条目时执行；从条目的 `ref_file.single` / `ref_file.multi` 读取本文件。没有启用条目时立即返回，不读取关联内容、不检索、确认、下载或回写字段。

单仓 Step 9 / 多仓 M-2 启动前由主会话准备一次，每任务在独立内置检查点消费。多仓子代理读取片段 `plan_path` 指向的根执行计划；片段中的 `orchestration_points` 只用于自定义步骤，不能推断本步骤启停。core-design 的开关、已有 Skill 字段和本地文件均不能开启 apply。计划或片段无效时停止并报告，不自行重建。

## 主会话前置准备（每轮一次）

单仓 Step 9 / 多仓 M-2 代理启动前，主会话依据内置步骤的启用条目执行本节。本节只准备关联，当前任务内容的消费留到 10.3.4；关闭时不加载本文件。

1. 只处理 tasks.md `## 代码生成任务` 的待办 1.x 任务；无待办直接返回。多仓在启动 M-2 代码生成代理前汇总各仓待办，以“仓名 + 任务编号”区分。
2. 读取 Skill 字段和已关联的本地内容；尊重「不使用（用户选择）」，不将其当成缺失关联。已有有效关联直接复用，不重复选型或确认。
3. 已锁定的同名内容丢失时按原决定补下，无须重新选型；需要新增 / 改选时才按共享规则的「CLI 命令与字段传递」准备候选：业务能力走 `offering` → `product-scenes` → `scene-skills`（`scenes --repo` 已返回产品及场景时复用），通用能力走 `skill search`，业务未命中再加 `experience search`。由主会话按任务组一次批量确认，然后按名称去重，用真实 Skill ID 调用 `skill download`，安装并回写。下载失败保留旧内容，仅验证旧内容仍适用时才复用。
4. 只在会话内保留本轮准备结果及未选用 / 失败状态，避免每任务重复检索、确认或重试；tasks.md 仍是持久关联唯一来源，不另建能力索引。多仓通过模板的 `{prepared_context}` 传入本仓准备状态和任务编号对应的锁定 / 不使用 / 失败结果；这是只读会话上下文，子代理仍从本仓 tasks.md 读取最终关联。

## 每任务消费（内置检查点，task 级）

1. 在单仓 10.3.4 / 多仓模板步骤 c 的内置检查点，复核根计划中本步骤条目仍启用，再读取当前任务锁定的 Skill / 经验内容，作为代码生成上下文；不得改写项目原则或跳过原验证步骤。
2. 复用主会话前置准备的结果，不再执行全量候选准备。明确不使用、无合适候选或本轮获取失败时继续原任务，不在每个任务弹窗或重新下载。
3. 循环中发现新的新增 / 改选需求时，汇总并预检其余待办任务，回到主会话的批量准备阶段统一处理；已有可用关联的任务可以继续，不逐任务临时弹窗。
4. 继续执行通用 pre-codegen 插槽中的已配置条目，然后进入原则自检与代码生成。

## 多仓执行

- 主会话从根执行计划判断启用并完成循环前准备，将根计划、本仓插槽片段及锁定结果交给各仓代理；根计划无启用条目时所有仓均跳过消费，通用插槽照常调度。
- 子代理在每任务内置检查点，从根计划启用条目的 `ref_file.multi` 读取本文件及共享规则，按本仓 tasks.md 读取已锁定内容；单纯补下同名内容可按原决定在本仓落地，不下载替代 Skill，不修改其他仓。
- 新增 / 改选需求只返回主会话汇总处理，禁止子代理各自提问。委托时传入根执行计划、本仓片段的绝对路径与本轮准备结果；子代理自行按启用条目的 `ref_file.multi` 读取本文件，再按其中 GATE 读取共享规则，不假设主会话已加载的文件自动进入其上下文。开关启用但准备结果缺失时返回主会话补齐，禁止各仓重新执行全量准备。
- 关闭时仅跳过新增消费行为；普通任务读取、checkbox 更新、M-2 代码生成以及其他已配置步骤照常执行。保留已有 Skill / 经验字段和本地文件，方便以后重新启用。

## 输出

汇报实际使用的关联、用户指定 / Agent 自选 / 不使用及获取失败任务；失败说明后继续原任务，字段回写失败不得宣称成功。关闭时调度器不加载本文件；通用计划摘要可报告该条目关闭，不执行本输出段。
